# Arquivo histórico

Esta pasta preserva materiais de auditoria e documentos substituídos que ainda podem ajudar a explicar decisões anteriores.

- `audits/`: comparações e diagnósticos pontuais, fora da raiz pública.
- Materiais locais ou brutos não pertencem aqui; devem ficar em `.local-reference/`, que não é versionada.

Os arquivos de `audits/` registram comparações de julho de 2026 que antes ficavam como `diff.txt` e `cached-diff.txt` na raiz.
