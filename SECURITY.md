# Política de segurança

## Relato responsável

Envie vulnerabilidades de forma privada para `bemesportivo@yahoo.com` com:

- descrição do problema;
- URL, endpoint ou arquivo afetado;
- passos mínimos para reprodução;
- impacto observado;
- sugestão de correção, se disponível.

Não publique credenciais, tokens, dados pessoais ou instruções de exploração contra a produção em issues públicas.

## Escopo

A branch `main` e o domínio `bemesportivo.com` representam a versão suportada. Código em `archive/`, protótipos locais e dependências de terceiros fora do controle do projeto não são ambientes suportados.

## Expectativa

O recebimento será confirmado assim que possível. Correções críticas têm prioridade sobre novas funcionalidades e só são publicadas depois de testes proporcionais ao risco.
