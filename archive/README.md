# Arquivo histórico

Este diretório preserva implementações substituídas para consulta. Nada aqui entra no build, nos testes de qualidade ou no deploy.

- `platforms/netlify/`: backend da plataforma anterior.
- `prototypes/frontend-v1/`: protótipo modular descontinuado.
- `public-assets/`: recursos públicos antigos sem consumidores atuais.

Não corrija ou evolua código em `archive/`. Se uma ideia voltar ao produto, implemente-a novamente na estrutura ativa e com testes atuais.
