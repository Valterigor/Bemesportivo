# Fontes de aplicação

`src/apps/` contém entradas editáveis que o build transforma em bundles públicos.

No Meu Caminho Be:

- `auth.js`: autenticação, sessão, consentimento e exclusão de conta.
- `account.js`: continuidade e sincronização entre aparelhos.
- `continuity-crypto.js`: criptografia do fluxo de continuidade.

Edite estas fontes e execute `npm run build`. Não edite os bundles correspondentes em `js/`.
